# DL Group Two – Demonstration Test Checklist

1. Sign in using the demonstration administrator account.
2. Open Books; search, add a book, edit it and delete an unused test book.
3. Open Members; verify the nine group members and the demonstration member; add/edit a test member.
4. Open Loans; issue a book to an active member and verify the due date is 14 days ahead.
5. Attempt to issue the same title to the same member again; the system should reject the duplicate active loan.
6. Attempt to issue a book with no available copies; the system should reject it.
7. Return the issued book; available copies should increase by one.
8. Suspend a test member and verify the member cannot borrow. Restore the member to active afterwards.
9. Verify authors and categories can be listed and maintained.
10. Log out and confirm protected pages redirect to login.

Run these tests on a local copy of the database. Avoid changing the original demonstration records before the assessed presentation.
